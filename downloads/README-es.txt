Firmware SO-SHO verificado localmente

Este ZIP contiene seis perfiles UF2 compilados localmente el 28-10-2026.
La pareja normal es sosho_R_trackball.uf2 para el Central derecho y
sosho_L_trackpad.uf2 para el Peripheral izquierdo. Usa una pareja compatible.

Para escribir por USB, pon solo el lado derecho en modo bootloader. La tecla física
inferior derecha está reservada para el bootloader del Central derecho y el editor Web
no permite cambiarla por una tecla normal. La misma posición del lado izquierdo no
ejecuta una acción de bootloader.

El guardado en tiempo de ejecución de suspensión, mapa y macros requiere el firmware
con la extensión RPC de SO-SHO. Se verificaron la compilación local y la generación UF2;
no se afirma un guardado físico hasta que el editor Web muestre coincidencia al releer.
