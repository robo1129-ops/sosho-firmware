# SO-SHO trackpad gesture build

このフォルダのUF2は、現在のSO-SHOキーマップと分割通信を維持したまま、トラックパッドの操作を追加したローカル検証ビルドです。全パターンをまとめたZIPは `sosho-firmware-latest-local.zip` です。今回の調整版（スリープなし・右トラックボール＋左トラックパッド）は `sosho-sleep-off-r-trackball-l-trackpad.zip` です。

## 書き込むファイル

通常の構成では、右側のCentralへ `sosho_R_trackball.uf2`、左側のPeripheralへ `sosho_L_trackpad.uf2` を書き込みます。

- `sosho_R_trackball.uf2`: 右・Central・トラックボール
- `sosho_L_trackpad.uf2`: 左・Peripheral・トラックパッド
- `sosho_R_trackpad.uf2`: 右・Central・トラックパッド構成を使う場合
- `sosho_R_none.uf2`: 右側をブランクのダミーモジュールにする場合

## トラックパッドの操作

- 中央付近で通常に動かす: ポインター移動
- 短く触れて離す: 左クリック
- 短いタップを2回: 左クリック2回を送り、OSのダブルクリックとして動作
- 500ms以上触れ続ける: 右クリック
- 長押ししたまま動かす: 右ボタンを押したドラッグ
- 外周帯から触れ始めて円周方向になぞる: 今回の復旧版では無効（右トラックボールのスクロールレイヤーを使用）

今回の復旧版では、ポインター無反応の原因になった絶対座標ベースの外周スクロール処理を通常経路から外しています。Pinnacle公式relative modeの移動とタッチイベントを使うため、接触位置を変えてもポインターが瞬間移動したり、イベント順序によって無反応になったりしません。カーソル移動は標準の1:1に戻し、実機の向きに合わせてX軸だけを反転しています。Y軸は標準方向です。

## 注意

この成果物はローカルでビルド済みですが、実機への書き込みと人の操作による確認はまだ行っていません。書き込み前に、現在使っているUF2を保存してください。キーマップやStudio通信の既存機能は変更していません。
