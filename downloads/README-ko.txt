SO-SHO 로컬 검증 펌웨어

이 ZIP에는 2026-10-28에 로컬에서 빌드한 6개 UF2 프로필이 들어 있습니다.
일반 구성은 오른쪽 Central의 sosho_R_trackball.uf2와 왼쪽 Peripheral의
sosho_L_trackpad.uf2입니다. 서로 맞는 프로필을 한 쌍으로 기록하세요.

USB로 기록할 때는 오른쪽만 부트로더 모드로 전환합니다. 레이어 3 사용 중 실수로
UF2 모드에 들어가지 않도록 공장 키맵에는 물리 부트로더 키를 배치하지 않았습니다.
부트로더 동작은 Web 편집기의 특수 동작 팔레트에서 선택할 수 있습니다.

런타임 절전, 키맵과 매크로 저장은 SO-SHO 확장 RPC 펌웨어가 필요합니다.
로컬 빌드와 UF2 생성은 확인했으며, Web 편집기에서 다시 읽기 일치가 보이기 전에는
실기 저장 성공으로 간주하지 않습니다.
