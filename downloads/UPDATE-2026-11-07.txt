Included fixes
- The common sensor boot wait and PMW3610 power-up wait are both 40 ms instead
  of the previous unconditional 1000 ms delay. This reduces the apparent
  wake-up pause for the trackball and trackpad. Deep ZMK sleep can still
  require Bluetooth reconnection time.
- Half/full-width key is HID LANG5 (usage 0x94) in firmware and Web RPC.
- Tap a key, release it, then hold the same key: the tap binding is held.
  This also applies when the hold binding is a layer switch. A first press-and-
  hold still keeps the configured hold binding such as Shift, Alt, or a layer.
- Macro transport supports up to 64 steps per macro with a default 1 ms delay.
- Macro Bluetooth actions: select profile BT0-BT4, next/previous profile,
  disconnect profile, clear selected profile, and clear all profiles.

Important limitation
ZMK selects one active Bluetooth profile for keyboard output. The BT macro
actions select or clear profiles; they do not broadcast one keystroke to several
hosts simultaneously.

After flashing, verify that the bootloader drive disappears and the right side
returns as the normal USB keyboard/pointing device. Then use the Web app to
read, change, save, and read back the keymap. The final device state should be
this 2026-11-07 build, not the pre-test backup.
